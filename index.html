Стратегия

Видение на 2026–2028

2026 — Фундамент
Microservices & Event-Driven (декомпозиция микросервисов)
Переход с монолитов на event-driven архитектуру. Kafka как шина событий, domain-driven дизайн сервисов, API Gateway для всех продуктов.
DevOps зрелость
Полный CI/CD pipeline, GitOps в Kubernetes, Prometheus + Grafana alerting, SLO/SLA для всех критических сервисов. GitLab как единая платформа.
Внутренние бизнес-процессы
Отпуск, командировка, увольнение, АХД — всё через портал. Заявка уходит автоматически по маршруту согласования, статус виден в реальном времени, HR разгружен.
Рост команды
Набор Go-разработчиков, DevOps-инженеров и аналитиков данных. Целевой размер: 10–15 человек. Программа обучения: Golang, Camunda, Kafka, OAuth2.
2027–2028 — Рост
Единый UI-Kit
Все продукты банка выглядят и работают одинаково. Меньше дублирования, быстрее разработка новых фич.
Big Data & Customer Intelligence
Мы знаем каждую транзакцию клиента — но пока не используем это. Построив data pipeline, банк начнёт понимать: кому предложить кредит, кто готов к депозиту, кто вот-вот уйдёт к конкуренту.
Embedded Finance / Banking as a Service
Партнёры встраивают финансовые сервисы Tenge Bank в свои приложения — кредиты, платежи, переводы — через готовый WebView. Банк расширяет охват без новых отделений и без маркетинга.
E-commerce для мерчантов
Платёжные страницы, инвойсинг, аналитика продаж — всё в одном кабинете. Меньше интеграций, больше продаж.
